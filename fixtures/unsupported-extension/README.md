# Расширение неподдерживаемого формата

Маленький проект для проверки дерева метаданных: рядом с основной конфигурацией
лежат два расширения, и у одного из них версия выгрузки вне поддерживаемых.
В каталогах только `Configuration.xml`, файлов объектов нет.

| Каталог | Версия выгрузки | Что проверяем |
| --- | --- | --- |
| `src/cf` | 2.20 | основная конфигурация, пустая, из `init-empty-cf` |
| `src/cfe/New` | 2.20 | расширение «НовыйФормат» из `init-empty-cfe` с ролью в составе, читается |
| `src/cfe/Old` | 2.9 | расширение «СтарыйФормат» в раскладке выгрузки платформы 8.3.12 с языком и стилем в составе, состав не читается |

Каталог `src/cfe/Old`, подставленный вместо `src/cf`, даёт отказ `project-metadata-tree`
на неподдерживаемой версии основной конфигурации.
